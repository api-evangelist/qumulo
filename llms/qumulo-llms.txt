# Qumulo

> Qumulo is an enterprise data platform delivering a single, unified file and
> object storage system across on-premises, edge, and public cloud (AWS, Azure,
> GCP) at exabyte scale. Every Qumulo cluster exposes a versioned REST API
> (v1/v2/v3+) and the `qq` CLI for managing files, snapshots, quotas,
> replication, multi-protocol access (NFS/SMB/S3/FTP), networking, cluster
> operations, and monitoring/analytics.
